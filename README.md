# Futbol Draft

Çok oyunculu futbol draft ve lig oyunu.

## Proje dosyaları
- `index.html`: Arayüz ve oyun ekranları
- `app.js`: Draft akışı, çark, koruma, taktik seçimleri ve maç motoru
- `styles.css`: Görsel tasarım
- `players.json`: Futbolcu havuzu
- `firebase-config.js`: Firebase web uygulaması yapılandırması
- `firestore.rules`: Firestore güvenlik kuralları
- `functions/`: Firebase Cloud Functions

## Güncel oyun kuralları
Çark, koruma, FUTBOLCU KAYBET, draft sonrası aşamalar, altı gol kuralı ve tüm taktik bonusları için `KURALLAR.md` dosyasına bakın.

## Kurulum ve yayınlama
Firebase yapılandırması, hesap sistemi ve yayınlama adımları için `KURULUM-VE-DEPLOY.md` dosyasını okuyun.

Bu ZIP canlı siteye otomatik olarak yüklenmez. Yayına almadan önce yerel test ve Firebase yapılandırma kontrolü yapılmalıdır.
